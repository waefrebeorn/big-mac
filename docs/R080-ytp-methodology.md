# R080 — YTP Editing Methodology: Context-Aware Approach

## The Problem with Random Clips

Previous experiments (001-025) were **context-blind**: random 8-10 second clips extracted at arbitrary timestamps, with effects applied generically. This produces "repetitive trash" — technically functional edits with no artistic merit, no understanding of the source, and no creative intent.

## The Context-Aware Workflow

### Step 1: Source Analysis
Before editing ANY source, you must understand what's in it:
1. **Extract frames** at regular intervals (every 5-10 seconds)
2. **Analyze each frame** with vision tools to identify:
   - Characters present
   - Actions occurring
   - Dialogue moments
   - Visual quality/style
   - Memorable/iconic moments
3. **Build a scene map**: timestamp → content description
4. **Identify YTP exploitation points**: What makes this source editable?

### Step 2: Moment Selection
Choose specific moments to edit based on:
- **Iconic value**: Is this a recognizable moment from the source?
- **Exploitable properties**: Does it have clear audio/visual features to manipulate?
- **Emotional peak**: Is this a high-energy or distinctive moment?
- **Phoneme content** (for sentence mixing): Does it contain useful syllables?

### Step 3: Intentional Transformation
Apply effects that make SENSE for the specific content:
- **Angry character** → earrape, demon voice, stutter (amplifies anger)
- **Dialogue moment** → sentence mixing, pitch shift (transforms speech)
- **Calm moment** → sudden chaos, speed ramp (contrast)
- **Group scene** → individual isolation, chroma key (recontextualize)

### Step 4: Document Context
For each source, maintain a `context.md` file with:
- Scene map (timestamp → content)
- Character list
- YTP exploitation notes
- Visual style description
- Watermark/quality notes

## Lessons Learned

1. **Never edit blind** — always analyze first
2. **Quality > quantity** — one context-aware edit beats 10 random ones
3. **Source knowledge is power** — knowing WHY a source is iconic informs HOW to edit it
4. **Effects serve the content** — not the other way around
5. **Document everything** — context files enable future creative edits

## The Recursive Loop (Corrected)

1. **Research** → Find new sources via archive.org, YouTube, Reddit, forums
2. **Acquire** → Download full source files (not clips)
3. **Analyze** → Extract frames, build scene map, identify exploitation points
4. **Document** → Write context.md for each source
5. **Select** → Choose specific moments with intent
6. **Transform** → Apply context-appropriate effects
7. **Evaluate** → Score for accuracy, creativity, technical execution
8. **Transcode** → Shrink full sources to manageable clips (preserving originals)
9. **Repeat** → Each cycle builds knowledge and improves quality
