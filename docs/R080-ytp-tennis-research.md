# R080 — YTP Tennis: Comprehensive Research & Rules

## What is YTP Tennis?

**Video Tennis** (aka YouTube Poop Tennis, YTP Tennis, Remix Tennis) is a competitive/collaborative art form where two or more creators take turns editing each other's videos in a back-and-forth "tennis" pattern. It evolved from Photoshop Tennis and was pioneered by **conradslater** in August 2007 on the YouChew forums.

## Core Rules (The "Vanilla" Format)

### Standard Match Structure
- **6 rounds** total (each player edits 3 times)
- **1v1 format** (also exists: doubles, 3-way, multi-way)
- Player A creates a "serve" (original edit)
- Player B downloads it, edits it, uploads as "Round 2"
- Player A downloads Round 2, edits it, uploads as "Round 3"
- Continues alternating until Round 6
- Each round must be a **direct edit of the previous round** (not a new creation)

### Key Rules
1. **Source chaining**: Each round must use the previous round as its base media
2. **No source replacement**: You cannot swap the original source material
3. **Transformation requirement**: Each round must visibly transform the previous one
4. **Time limits**: Vary by tournament (typically 24-72 hours per round)
5. **No pre-made content**: Must edit the actual previous round file

### Judging Criteria
- **Creativity**: Originality of transformations
- **Technical skill**: Quality of editing execution
- **Humor**: Comedic value (in classic format)
- **Response quality**: How well you respond to opponent's edits
- **Source exploitation**: Creative use of the source material's properties

## Types of Tennis

| Type | Players | Description |
|------|---------|-------------|
| **Vanilla 1v1** | 2 | Standard 6-round back-and-forth |
| **Doubles** | 4 | Teams of 2, alternating |
| **3-Way** | 3 | Three players rotate editing |
| **Multi-Way** | 4+ | Round-robin editing |
| **Chain** | Many | Each person edits the previous in a long chain |
| **Tournament** | Many | Elimination brackets of 1v1 matches |

## Tennis Culture & History

### Timeline
- **2007-08-11**: First match (conradslater vs Misselaineous10)
- **2007-10**: RabbitSnore creates Tennis Review series
- **2008-01**: Official rules established (6-round standard)
- **2008-05**: "Tennis Fucks" staff formed
- **2008-06**: First Tennis Cup tournament
- **2008-12**: MycroProcessor vs GameBop — avant-garde turn
- **2009**: "Golden Age" — classic vs technical schism
- **2010-11**: Tennis separates from main YTP community
- **2011**: MycroProcessor's "5" — defining avant-garde work
- **2019**: YouWouldBeWelcome archive account launches

### Key Figures
- **conradslater**: Creator of first match, YouChew founder
- **RabbitSnore**: "King of Tennis", created rules & reviews
- **RAKninja**: Prolific player, meme creator ("ROBOT BUNNIE BOOBIES")
- **MycroProcessor**: Avant-garde pioneer, technical innovator
- **GameBop**: Technical evolution, middle period refinement
- **Crash2991**: Classic style advocate
- **Moogle**: Introduced Touhou to tennis

### Classic vs Technical Schism
- **Classic school**: Minimal effects, humor-focused, source exploitation
- **Technical school**: Dense editing, visual complexity, abstract
- **The debate**: "Effects everywhere" vs "just being funny"
- **Resolution**: Both styles coexist; different matches favor different approaches

## How Tennis Relates to YTP Skills

### Skills Developed
1. **Rapid transformation**: Must completely change a video in limited time
2. **Source analysis**: Quickly identify exploitable properties of incoming media
3. **Response editing**: React to opponent's creative choices
4. **Style matching/adaptation**: Work within constraints of previous round
5. **Technical speed**: Fast turnaround under time pressure

### Tennis Techniques
- **Repoop**: Re-editing someone's edit (the fundamental tennis action)
- **Source layering**: Adding new sources on top of existing edit
- **Effect stacking**: Building complexity round by round
- **Audio remixing**: Transforming the sound design each round
- **Visual escalation**: Each round more intense than the last

## Scoring Systems

### Accuracy Score (How well you follow the rules)
- Used correctly: 100%
- Wrong source used: -50%
- Missing round: disqualification
- Late submission: -10% per hour

### Creativity Score (How original your contribution)
- Based on: novelty of transformation, unexpected techniques, humor, technical innovation
- Scored by: judges (in tournaments) or community voting
- Scale: 1-10 in categories: originality, technique, entertainment, response quality

### Quality Metrics for YTP Edits (General)
1. **Source recognition**: Can viewers identify the source?
2. **Transformation degree**: How different is output from input?
3. **Technical execution**: Clean edits vs sloppy?
4. **Comedic timing**: Do jokes land?
5. **Audio-visual sync**: Is sound matched to visuals?
6. **Pacing**: Is the edit well-timed?
7. **Coherence**: Does it make sense (even if absurdist)?
